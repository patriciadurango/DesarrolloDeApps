# Portafolio de actividades (A01-A04)

# A01 - HolaMundoApp
Aplicación básica creada para familiarizarse con Android Studio y comprender los fundamentos del desarrollo en esta plataforma.

# A02 - LayoutApp
App que permite experimentar con distintos tipos de layouts en Android, como LinearLayout, RelativeLayout y ConstraintLayout, facilitando la organización y disposición de los elementos en la interfaz de manera flexible y adaptable.

# A03 - TouchApp
La aplicación captura acciones como toques simples y toques prolongados, con un botón simple en Android Studio.

# A04 - FragmentsApp
Aplicación diseñada para mostrar cómo organizar la interfaz en bloques independientes usando Fragments. Cada bloque maneja su propio contenido, lo que permite separar las secciones de la app y navegar entre ellas de manera ordenada, práctica y fácil de mantener.
